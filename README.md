# 🎬 WebAnimeKu

[![GitHub stars](https://img.shields.io/github/stars/RayzeWanggy/WebAnimeKu)](https://github.com/RayzeWanggy/WebAnimeKu/stargazers)
[![GitHub forks](https://img.shields.io/github/forks/RayzeWanggy/WebAnimeKu)](https://github.com/RayzeWanggy/WebAnimeKu/network)

**WebAnimeKu** adalah website streaming anime subtitle Indonesia dengan koleksi lengkap dan update terbaru.

## ✨ Fitur Utama

- 🎬 **60+ Anime** - Koleksi anime lengkap berbagai genre
- 🔍 **Search & Filter** - Cari anime berdasarkan judul atau genre
- 📋 **Kategori** - Ongoing, Completed, Movies
- 🏷️ **10+ Genre** - Action, Adventure, Comedy, Drama, Fantasy, Romance, Sci-Fi, Slice of Life, Sports, Thriller
- 📅 **Jadwal Rilis** - Update jadwal tayang setiap hari
- 📱 **Responsive** - Tampilan optimal di semua perangkat
- 🌐 **Subtitle Indonesia** - Semua anime dengan subtitle Indonesia
